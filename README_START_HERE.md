## 📞 Technical Support

### What to check first:
1. Is server running? `npm start` → http://localhost:3001
2. Check console for error messages
3. Verify `.env` file has all required variables
4. Make sure you're on the right port (3001, not 3000)
5. Restart server after any config changes

### Common error messages:
- "Email transporter setup failed" → Fix: EMAIL_SETUP_GUIDE.md
- "Cannot create checkout session" → Fix: Verify Stripe keys
- "Webhook not working" → Fix: WEBHOOK_SETUP_GUIDE.md
- "Page won't load" → Fix: Check server is running at :3001
